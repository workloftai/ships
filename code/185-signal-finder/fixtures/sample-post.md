# title: Why we stopped estimating in points (synthetic fixture)
# date: 2026-06-14

This is a synthetic blog post by Sam Example of Example Labs, bundled so the tool runs without a network or an API key.

We stopped estimating in story points this spring. I think points mostly measured how confident people felt on a Monday.

Instead we size work as one day, one week, or too big. Anything too big gets split before it starts.

The mistake we made for years was treating the estimate as a promise rather than a guess we would revise.
