# summarise-thread

Turn a long thread into three things, in this order:

1. **Decision so far** — one sentence. What has actually been agreed. If nothing
   has, say "no decision yet" rather than inventing one.
2. **Open questions** — the things still blocking a decision, as a short list.
   Each should be answerable, not vague ("what is the budget", not "unclear").
3. **Next step + owner** — the single next action and the named person who holds
   it. If no owner is named, say so; do not assign one yourself.

Rules:
- Quote sparingly. The reader has the thread; they want the state of it.
- Do not smooth over disagreement. If two people want different things, name both.
- No preamble. Lead with the decision line.
